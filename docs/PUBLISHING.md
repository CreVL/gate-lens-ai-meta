## Updates

Use the existing checkout and inspect changes before publishing:

```powershell
git status
git diff
git add <FILES_YOU_REVIEWED>
git diff --cached --check
git diff --cached
git commit -m "Describe the change"
git push origin main
```

The file-list placeholder is not a literal command argument. Keep build output, node_modules, generated vendor assets, .artifacts, local.properties, keys and raw data exports outside Git. Never use force-add to bypass ignores. Dependencies are installed from the pinned manifests and lockfiles.

## Positioning and media

Describe the project as an experimental prototype validated in the official Meta Display Simulator. Photos originate in a 3D scene; the detector supports its known label design. Field names and nesting in the consumed JSON subset are retained while identities and assignment values are fictional.

Do not claim physical-glasses validation, production deployment, arbitrary seal recognition, tamper detection, customer integration, vendor endorsement or measured savings.

The LinkedIn draft and recording plan are supplied separately. Link to this repository. A 45–60 second demonstration can show a wrong-view rejection, close label retake, OCR result and mismatch incident. No barrier opening is part of this inspection demonstration.
