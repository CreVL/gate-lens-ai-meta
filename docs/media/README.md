# Runtime media

`inspection-read.png`, `inspection-unreadable.png` and `inspection-incident.png` are selected screenshots from the public GateLens build in the official Meta simulator. All visible assignments, people, companies and registrations are fictional. The 3D scene is procedural. These are simulator results, not recordings through physical glasses.

The browser tests generate source screenshots in ignored `.artifacts/vision/`. Video recordings are distributed separately from Git history. SDK and extension branding visible in the runtime UI identifies the actual test tool, not affiliation or endorsement.
